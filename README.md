# 2026-02-React-Study
[26-27 GDG on Campus Sookmyung 7기] 1분기 스터디(React)를 위한 저장소입니다.

각 주차의 학습 내용과 과제는 Notion의 React Study 커리큘럼을 참고해주세요.

## 📚 스터디 진행 방식

1. 매주 커리큘럼에 해당하는 내용을 스스로 학습합니다.
2. 각 주차에 첨부된 강의 및 학습 자료를 활용하거나 필요한 내용을 자유롭게 추가 학습합니다.
3. 학습한 내용은 각자 기록해두고, 티스토리 작성 순서가 돌아오면 해당 주차의 학습 내용을 정리하여 업로드합니다.
4. 매주 주어진 과제를 수행하고 GitHub를 통해 제출합니다.
5. 수요일 대면 스터디에서 코드 쉐어와 토론 및 배운 점 공유를 진행합니다.

## 💻 과제 제출 방법

1. 매주 과제는 GitHub에 올려주세요.
2. **본인의 깃허브 username**으로 과제 브랜치를 생성하여 과제를 수행해주세요.
3. 과제를 완료한 후 본인 깃허브 username 브랜치에서 `main` 브랜치로 PR을 Open해주세요.
4. PR Open 시 **Reviewer로 팀 멤버(나연우, 이나경)를 꼭 추가**해주세요.
5. PR에는 해당 주차 강의를 통해 **배운 점과 스터디원들과 공유하고 싶은 부분**을 함께 작성해주세요.
6. Merge는 팀 멤버의 승인 이후에 가능합니다.



해당 주차의 T(=Team member) 폴더의 src 폴더를 참고하여 과제를 수행합니다.

매주 각자의 이름으로 폴더를 만들어 과제를 진행해주세요!




### PR 작성 규칙

**주차별 PR 제목**

`[WEEK01 이름] 학습 주제`

예시)
`[WEEK01 홍길동] JSX와 React 컴포넌트 기초`

**Commit 메시지**

`[WEEK01] feat: 커밋 내용`

예시)
`[WEEK01] feat: 프로필 카드 컴포넌트 구현`

- feat : 기능 추가
- fix : 버그 수정
- refactor : 리팩토링
- docs : 문서 수정
- test : 테스트 또는 테스트 코드 추가
- style: 코드 포맷팅, 세미콜론 누락, 코드 의미에 영향 없는 변경
- build: 빌드 시스템 수정, 외부 종속 라이브러리 수정(gradle, npm 등)
- rename : 파일명 또는 폴더명 수정
- remove : 코드 또는 파일 삭제
- chore : 그 외 자잘한 수정
